Connections runs locally

The Connections solver loads three sentence-embedding models (a couple of gigabytes of memory), which is more than this free demo host provides. The Wordle tab is fully live here.

To try Connections, run it on your own machine:

git clone https://github.com/krishv2108-droid/word-puzzle-solvers
cd word-puzzle-solvers && pip install -r requirements.txt
python data/download_connections.py
python -m src.connections.train
uvicorn src.api.main:app

The README has screenshots, measured accuracy and the full write-up.

Enter the 16 words and press Solve all for a full proposal with a confidence for each group, or Give me a group for a single hint.

How good is it? On 150 held-out past puzzles it gets about 0.7 of the 4 groups right on average, and fully solves roughly 3 in 100. Confidence percentages are calibrated against those results, so treat suggestions as hints, not answers.
